# Interstellar Explorer Log (11ty)

## Run it

```bash
npm install
npm run start
```

Eleventy will serve the site and rebuild on save.

## What this includes (matches the lab requirements)

- **4 HTML pages at build output**: Home, About, and **two blog posts** (written in Markdown).
- **Liquid layout** shared across all pages: `src/_includes/layout.liquid`
- **Shortcode** for reusable content: `signal` (defined in `.eleventy.js`) and used on Home/About/Posts
- **10+ CSS rulesets** with a consistent deep-space theme: `src/styles/screen.css`
- **AI citation comment** inside the shared layout HTML head.
